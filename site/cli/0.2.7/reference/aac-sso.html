AAC CLI 0.2.7

aac sso

Platform single sign-on: IdP connections, login, sessions and recovery keys.

Synopsis

aac sso [-h] <command> [<args>]

Commands

Command Description
aac sso register-idp Register a tenant↔IdP connection.
aac sso generate-idp-recovery-key Generate offline tenant IdP recovery-key artifacts.
aac sso enroll-idp-recovery-key Enroll a tenant's IdP recovery public verifier.
aac sso list-idp-recovery-keys List IdP recovery-key lifecycle metadata.
aac sso rotate-idp-recovery-key Replace the ACTIVE IdP recovery public verifier.
aac sso revoke-idp-recovery-key Terminally revoke the ACTIVE IdP recovery key.
aac sso request-idp-repair Sign and submit one exact IdP connection repair request.
aac sso approve-idp-repair AAC Ops approves one exact tenant-signed IdP repair.
aac sso list-idp List safe tenant IdP connection handles without authentication.
aac sso replace-idp Replace one tenant IdP connection from a complete file.
aac sso logout Delete the cached AAC session for a tenant.
aac sso whoami Show cached session identity/expiry and the profile's saved AAC-assigned domain.
aac sso login Sign in via your tenant's IdP; caches an AAC session.

Argument Type Required Default Description
-h, --help flag no — show this help message and exit
