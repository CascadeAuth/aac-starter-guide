For your first authenticated reservation, follow the numbered Docker journey. Use these pages when you need a particular installation, integration or operational procedure.

Task Reference
Deploy your own tenant and agents, including a 100-agent chain Deployment
Understand authority, integrate native AAC or use the optional A2A example Protocol and integration
Diagnose failures, inspect evidence, rotate credentials and upgrade Operations
Install a standalone binary, verify a container or audit artifacts — optional Artifacts
Understand key roles and custody Keys and certificates
Register developer/enterprise tenants and use CLI commands Versioned CLI user guide and reference
Discover and render execution evidence Execution graphs
Find upgrade instructions by release Release note

Manual recipes in the integration reference are optional fixtures for that specific protocol example. The default journey uses maintained CLI setup and the packaged Compose application.
