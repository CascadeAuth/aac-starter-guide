aac chain

Discover chains and inspect their audit observations.

Synopsis

aac chain [-h] <command> [<args>]

Commands

Command Description
aac chain list List observed chains visible to your tenant.
aac chain show Chronological cross-org timeline (participant tenants only).

Arguments

Argument Type Required Default Description
-h, --help flag no — show this help message and exit
