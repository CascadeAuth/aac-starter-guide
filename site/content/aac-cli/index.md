# AAC CLI

Install `aac-cli` to get both `aac` for tenant and agent setup and `aeg` for
inspecting execution evidence. Requires Python 3.11 through 3.14.

```sh
python -m pip install --upgrade aac-cli
```

- [Configure and maintain a tenant](/cli/guide/)
- [Look up a command](/cli/reference/)
- [Find and interpret an execution](/aeg/)
- [Look up an AEG command](/aeg/reference/)

These stable pages describe the latest supported release. Upgrade your CLI to
use the documented commands. Historical artifacts and release evidence remain
available from their release publishers; this site does not maintain old guides.
