# References

For your first authenticated reservation, follow the
[numbered Docker journey](https://cascadeauth.github.io/aac-starter-guide/).
Use these pages when you need a particular installation, integration or
operational procedure.

| Task | Reference |
|---|---|
| Deploy your own tenant and agents, including a 100-agent chain | [Deployment](deployment.html) |
| Understand authority, integrate native AAC or use the optional A2A example | [Protocol and integration](protocol.html) |
| Diagnose failures, inspect evidence, rotate credentials and upgrade | [Operations](operations.html) |
| Install a standalone binary, verify a container or audit artifacts — optional | [Artifacts](artifacts.html) |
| Understand key roles and custody | [Keys and certificates](keys-and-certificates.html) |
| Register developer/enterprise tenants and use CLI commands | [Versioned CLI user guide and reference](https://cascadeauth.github.io/aac-starter-guide/cli/) |
| Discover and render execution evidence | [Execution graphs](aeg.html) |
| Find upgrade instructions by release | [Release note](release-notes.html) |

Manual recipes in the integration reference are optional fixtures for that
specific protocol example. The default journey uses maintained CLI setup and
the packaged Compose application.
