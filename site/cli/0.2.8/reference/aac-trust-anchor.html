aac trust-anchor

Inspect YOUR tenant's trust-anchor state (keys + ingest ledger).

Synopsis

aac trust-anchor [-h] <command> [<args>]

Commands

Command Description
aac trust-anchor list All your keys — every lifecycle state, both roles.
aac trust-anchor describe One key: full lifecycle + stored public PEM.
aac trust-anchor revoke Terminally revoke one root-signing key (session required).
aac trust-anchor ingest-history Accepted publishes from the ingest ledger, newest-first.

Arguments

Argument Type Required Default Description
-h, --help flag no — show this help message and exit
